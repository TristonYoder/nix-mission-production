# CG fonts

Font files dropped in this folder (`.ttf`, `.otf`, `.ttc`, `.dfont`, subfolders
are fine) are installed on every CG machine on the next `./deploy --role cg`.
Remove a file and it is uninstalled on the next deploy.

**This repo is public.** Only commit fonts whose licence allows redistribution
(OFL, Apache, etc.). Keep commercial fonts out of here.
